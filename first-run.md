# First Run — Digital Communication Review Guide

Date: October 5, 2026

## Input

DIGI 130 Project 1 brief, pages 17–18, and the student's screenshots of their airline mood board and Photoshop layer panel. The student reported difficulty differentiating the fonts and organizing the layers.

## First output

| Concept | Example visible in the student's work | Why it matters |
| --- | --- | --- |
| Typography hierarchy | A large “fly beyond” heading, a smaller tagline, and labels for primary and secondary Futura type | Size and styling establish reading order and give text different roles. |
| Adjustment layer | A Hue/Saturation layer | Color can be adjusted without directly altering the image pixels. |
| Smart object | An AdobeStock image layer with a smart-object icon | The source image remains available for further edits. |
| Layer mask | A white mask thumbnail beside the image layer | A mask can control visibility without erasing source pixels. |

## Questions for the student

1. Which text should viewers read first, and which text should they read next?
2. How should the primary and secondary type differ in this airline brand?
3. Which of the three non-destructive techniques are actually used in the finished file, rather than merely present in the Layers panel?

## Uncertainty

The screenshot shows a mask thumbnail but does not establish whether it changes the visible image. The brief requests at least three non-destructive techniques; the screenshot alone does not prove that all three are demonstrated in the finished work.
